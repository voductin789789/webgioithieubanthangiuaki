Niềm Đam Mê Với Kỹ Thuật Tầng Thấp & Java OOP

Tôi không chọn lập trình chỉ vì những ứng dụng bóng bẩy bên ngoài. Tôi bị thu hút bởi cách dữ liệu được chia nhỏ thành từng mảng byte truyền qua cáp mạng, cách hệ điều hành bắt tay và cách các đối tượng Java tương tác với nhau trong bộ nhớ.

Trong quá trình học tại UTH, tôi tập trung rèn luyện Java Core SE 21 và Lập trình Mạng Socket TCP/IP. Khi gặp phải ngoại lệ hoặc lỗi deadlock đa luồng, tôi luôn có thói quen đọc kỹ stack trace và tài liệu Oracle Docs thay vì sao chép mù quáng.

Với vai trò là trưởng nhóm 9, tôi luôn ưu tiên việc viết code sạch (clean code), phân tách module rõ ràng để mọi thành viên đều có thể đọc hiểu và phát triển thuận lợi.
